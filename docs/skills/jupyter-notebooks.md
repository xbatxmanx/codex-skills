## العربية

### ما وظيفة المهارة؟

إنشاء أو مراجعة دفاتر SQL وPython توثق التحليل وتسمح بإعادته.

### متى تستخدمها؟

استخدمها عندما يكون هدفك: دفتر منظم مع خطوات ومصادر ونتائج قابلة للفحص. راجع حدود الاستخدام في الملف الأصلي قبل الاستدعاء، خصوصًا الفرق بين الفحص والإصلاح والتحقق.

### ماذا تجهّز؟

السؤال والبيانات والأكواد أو الدفتر الحالي. حدّد النطاق والهدف بوضوح، وأرفق المصادر التي تملك صلاحية استخدامها. المعلومات الناقصة تحتاج إلى توضيح؛ لا يُفترض توفر أدوات التشغيل بمجرد نسخ الملفات.

### ما النتيجة المتوقعة؟

دفتر منظم مع خطوات ومصادر ونتائج قابلة للفحص.

### مثال استدعاء

```text
$jupyter-notebooks أنشئ دفتر Python يعيد إنتاج هذا التحليل.
```

المثال قالب طلب، وليس نتيجة تشغيل. استبدل الإشارة العامة بالملف أو النطاق أو البيانات المطلوبة.
