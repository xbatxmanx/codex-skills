## العربية

### ما وظيفة المهارة؟

استخدام البيانات لتقييم البدائل ودعم توصية مرتبطة بقرار محدد.

### متى تستخدمها؟

استخدمها عندما يكون هدفك: تحليل وتوصية مع الأدلة والافتراضات وحدود الثقة. راجع حدود الاستخدام في الملف الأصلي قبل الاستدعاء، خصوصًا الفرق بين الفحص والإصلاح والتحقق.

### ماذا تجهّز؟

القرار والبدائل ومصادر البيانات والقيود. حدّد النطاق والهدف بوضوح، وأرفق المصادر التي تملك صلاحية استخدامها. المعلومات الناقصة تحتاج إلى توضيح؛ لا يُفترض توفر أدوات التشغيل بمجرد نسخ الملفات.

### ما النتيجة المتوقعة؟

تحليل وتوصية مع الأدلة والافتراضات وحدود الثقة.

### مثال استدعاء

```text
$product-business-analysis قارن هذه البدائل ووصِ بالأفضل بناءً على البيانات.
```

المثال قالب طلب، وليس نتيجة تشغيل. استبدل الإشارة العامة بالملف أو النطاق أو البيانات المطلوبة.

## English

### What does it do?

Use data to compare alternatives and support a concrete decision.

### When should you use it?

Use it when you need: An analysis and recommendation with evidence, assumptions, and confidence limits. Read the original usage boundaries before invoking it, especially the distinction between scanning, fixing, and verification.

### What should you provide?

The decision, alternatives, data sources, and constraints. Specify the scope and goal, and supply sources you are authorized to use. Missing inputs require clarification; copying files does not provide the runtime tools.

### What can you expect?

An analysis and recommendation with evidence, assumptions, and confidence limits.

### Example invocation

```text
$product-business-analysis Compare these options and recommend one based on the data.
```

This is a request template, not an execution result. Replace the generic reference with the relevant artifact, scope, or data.
